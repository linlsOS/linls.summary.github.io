#  脚本解释器

* shell极脚本都是以 #!开头，告知系统该文件的执行需要一个解释器。 常见的解释器类型如下:
```
#!/bin/sh
#!/bin/bash
#!/usr/bin/perl
#!/usr/bin/tcl
#!/bin/sed -f
#!/usr/awk -f
```

* #!/bin/sh linux系统上默认是bash，多数UNIX商业OS中也默认shell

# 调用脚本

执行脚本的三种方式：
```
#方式1
sh helloworld.sh
#方式2
bash helloworld.sh
bash +x helloworld.sh   
#方式3
./helloworld.sh   #需给文件授予执行权限
#实授予权限的方式如下
chmod +x helloworld.sh      #授予可执行权限
chmod +rx helloworld.sh     #授予任何人可执行可读和可执行权限
chmod u+rx helloworld.sh    #只给脚本的所有者可读和可执行权限
```

* sh 脚本执行su后对应的命令不再执行

例如如下脚本，su后对应的命令不再执行：
```
#!/bin/bash -x
su
echo 1
echo 2
```

* 这里对应的策略是分成两个脚本，以root用户身份执行某个脚本

```
#!/bin/bash
su -c "/path/to/script.sh" -s /bin/bash root
```

在android下执行如上脚本会提示如下提示：
```
su: invalid uid/gid '-c'
```

故将对应指令修改为：
```
su 0 sh test.sh
```

* sh 日志输出

在shell脚本中的打印输出通常会有echo和printf两种，前者会自动换行

如果 Linux 命令返回错误，那么错误不会保存在文件中。你可以使用 2>&1 将命令的输出和错误保存到同一个文件中，如下所示：
通常，0 代表标准输入，1 代表标准输出，2 代表标准错误。在这里，你要将标准错误（2） 重定向（&）到与标准输出（1）相同的地址。
```
command > file.txt 2>&1
```
